Geofenced & QR-Based Attendance Management System
Introduction
This is a comprehensive attendance management system designed for educational institutions. The platform utilizes a combination of geofencing and QR codes to ensure accurate and secure attendance tracking. The system is built with a backend in PHP and a MySQL database, while the frontend is developed using HTML, CSS, JavaScript, and Bootstrap for a modern, responsive user interface. It serves three distinct user roles: Admin, Teacher, and Student.

Key Features
Admin
The Admin has full control over the system, with the ability to manage all aspects of the platform.

Authentication: Secure login and logout.

Attendance Management: View all attendance records and take manual attendance when necessary.

User Management:

Add, edit, and delete student and teacher details.

Search for specific students or teachers.

Add students in bulk using an Excel file for streamlined onboarding.

Time Table Management: Add, update, and delete class timetables.

Campus Settings: Configure campus location and geofence settings to enable location-based attendance marking.

Teacher
Teachers have limited access, focused primarily on attendance-related tasks.

Authentication: Secure login and logout.

Attendance: Take and view attendance for their assigned classes.

Student
Students can use the platform to manage their own attendance records.

Authentication: Secure login and logout.

Attendance Marking: Mark attendance by scanning a QR code or through geofencing when within the designated campus location.

Profile: View and edit their personal profile information.

Attendance History: View their own attendance records.
